# Changelog

## 0.1.0 — 2026-11-23

First public source release.

- Non-custodial Bitcoin (testnet and mainnet derivation) and EVM wallet.
  Argon2id and AES-GCM vault. BIP39 backup check. Watch-only. No telemetry.
- Read-only NiceHash, Braiins Pool, and LAN CGMiner / Braiins OS connectors.
- Profitability calculator and a fee ranking that refuses to call a negative
  estimate a recommendation.
- Free wallet, 30-day Pro trial, Pro, Team, and white-label licence checks.
  Owner CLI issues offline Ed25519 keys. No payment processing.
- Desktop shell, Docker, and GitHub Actions for tests and a Windows installer.
- Interface in Polish, English, German, Russian, and Spanish.

Hashly does not hold funds, sell hashrate, or promise mining returns.
