# Privacy notice

**Draft for lawyer review. Not legal advice. Not a finished privacy policy.**

Published by **Hashly / Infinitas**. The software is offered by the Polish sole
proprietorship **Infinitas - Krzysztof Paweł Michalak**. The registered address,
NIP, and REGON are **to be inserted** before this notice is used with customers.

## What this software is

Hashly is a program you run. It is not an account and not a financial service.
It does not hold customer funds.

## Data that stays on your device

- The passphrase verifier, the encrypted seed, pool tokens, alert tokens, and
  a licence key, if you paste one.
- Language, currency, and the trial clock.

Hashly has no server that receives those. Uninstalling or clearing site data
deletes them from that profile. There is no backup in the cloud unless you
copy the encrypted file yourself.

## Data your device sends, only when you ask

- CoinGecko and mempool.space, for a public BTC price and difficulty.
- NiceHash or Braiins, if you connect an account, using the token you stored.
- A miner on your LAN, if you ask.
- Telegram or an HTTPS webhook, if you create that alert.
- A public mempool API, if you choose to broadcast a transaction you signed.

Those operators see the request. A pool token is visible to that pool, which
is the point of the call. Hashly does not add an analytics call.

## No telemetry

The program does not contain a telemetry client.

## Retention

There is no Hashly customer database in this software. The external services
above have their own retention. Read their notices.

## Your position under the GDPR

This draft assumes the sole proprietorship is the controller for the software
it publishes, and that most processing happens on the user's device under the
user's control. A lawyer needs to confirm the role, the legal basis, the
retention story, and whether a data processing addendum is needed for anyone
who self-hosts Hashly for other people.
